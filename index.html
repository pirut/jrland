Frontier Builder

Single-player survival sandbox with vertical building.

Move: WASD or Hold Right Click to path
Sprint: Shift
Primary Action (Interact / Gather / Attack): Left Click
Use Item: R
Build Mode: B
Place Building: Left Click (in build mode)
Build Floor Up / Down: X / Z (or Alt + Mouse Wheel)
Select Build: Click Build Catalog
Rotate Blueprint: Q
Hotbar: 1-9, Mouse Wheel, or Click
Inventory / Crafting: I
Advanced crafting requires a workbench nearby
Chat: T
Toggle Fullscreen: F (Esc exits)
Pause: P
Toggle Debug: `

Paused

Press P to resume.
